The model

Pay for what you need

Each service is its own line item. Run Web + SEO this month. Add UI/UX next month when the redesign starts. Only pay for what is active.

Month-to-month means you are never locked in. Scale up when things are moving, scale back when they are not. No penalty, no notice period beyond the current cycle.
